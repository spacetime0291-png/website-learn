## 16. Gelombang Berjalan dan Gelombang Stasioner

### A. Gelombang Berjalan Sinusoidal
* Hubungan Cepat Rambat: $v = \lambda f = \frac{\lambda}{T} = \frac{\omega}{k}$
* Persamaan Simpangan:
  $$y = \pm A \sin(\omega t \mp kx)$$
  * $+A$ (simpangan pertama ke atas), $-A$ (simpangan pertama ke bawah)
  * $-kx$ (gelombang merambat ke kanan $/ +x$), $+kx$ (gelombang merambat ke kiri $/ -x$)
  * $\omega = 2\pi f = \frac{2\pi}{T}$, $k = \frac{2\pi}{\lambda}$
* Fase ($\phi$) & Beda Fase ($\Delta\phi$): $\phi = \frac{t}{T} \mp \frac{x}{\lambda}, \quad \Delta\phi = \frac{\Delta x}{\lambda}$
* Hukum Melde (Cepat Rambat Kawat/Tali): $v = \sqrt{\frac{F}{\mu}} = \sqrt{\frac{FL}{m}} = \sqrt{\frac{F}{\rho A}}$

### B. Matriks Perbandingan Gelombang Stasioner
| Karakteristik | Gelombang Stasioner Ujung Terikat | Gelombang Stasioner Ujung Bebas |
| :--- | :--- | :--- |
| **Titik Pantul ($x = 0$)** | Menjadi **Simpul** | Menjadi **Perut** |
| **Persamaan Gelombang** | $y = 2A \sin(kx)\cos(\omega t)$ | $y = 2A \cos(kx)\sin(\omega t)$ |
| **Amplitudo Stasioner** | $A_s = 2A|\sin(kx)|$ | $A_s = 2A|\cos(kx)|$ |
| **Letak Simpul ($x_s$)** | $x_s = n \left(\frac{\lambda}{2}\right) \quad (n = 0, 1, 2 \dots)$ | $x_s = (2n + 1)\left(\frac{\lambda}{4}\right) \quad (n = 0, 1, 2 \dots)$ |
| **Letak Perut ($x_p$)** | $x_p = (2n + 1)\left(\frac{\lambda}{4}\right) \quad (n = 0, 1, 2 \dots)$ | $x_p = n \left(\frac{\lambda}{2}\right) \quad (n = 0, 1, 2 \dots)$ |
