## 17. Gelombang Bunyi

### A. Karakteristik Cepat Rambat
* Pada Gas: $v = \sqrt{\frac{\gamma R T}{M_r}}$
* Pada Zat Padat: $v = \sqrt{\frac{Y}{\rho}}$
* Pada Zat Cair: $v = \sqrt{\frac{B}{\rho}}$

### B. Matriks Frekuensi Harmonik Nada Bunyi
| Sumber Nada | Pola Frekuensi Harmonik ($f_n$) | Rasio Nada ($f_0 : f_1 : f_2 : f_3 \dots$) |
| :--- | :---: | :---: |
| **Dawai** | $f_n = (n + 1)\frac{v}{2L}$ | $1 : 2 : 3 : 4 \dots$ |
| **Pipa Organa Terbuka (POB)** | $f_n = (n + 1)\frac{v}{2L}$ | $1 : 2 : 3 : 4 \dots$ |
| **Pipa Organa Tertutup (POT)** | $f_n = (2n + 1)\frac{v}{4L}$ | $1 : 3 : 5 : 7 \dots$ |

### C. Intensitas, Taraf Intensitas, dan Efek Doppler
* Intensitas: $I = \frac{P}{A} = \frac{P}{4\pi r^2}$
* Taraf Intensitas ($TI$): $TI = 10 \log_{10}\left(\frac{I}{I_0}\right) \quad (I_0 = 10^{-12}\text{ W/m}^2)$
  * Jumlah $n$ sumber: $TI_n = TI_1 + 10\log_{10}(n)$
  * Jarak ($r_1 \to r_2$): $TI_2 = TI_1 - 20\log_{10}\left(\frac{r_2}{r_1}\right)$
* Efek Doppler: $f_p = \left(\frac{v \pm v_p}{v \mp v_s}\right) f_s$
  * Pendengar mendekat: $+v_p$, Pendengar menjauh: $-v_p$
  * Sumber mendekat: $-v_s$, Sumber menjauh: $+v_s$
* Pelayangan Bunyi: $f_{\text{layang}} = |f_1 - f_2|$
