## 2. Logaritma ($^a\log b = c \iff a^c = b; \ a>0, a\neq 1, b>0$)
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| $^a\log 1 = 0$ | $^5\log 1 = 0$ |
| $^a\log a = 1$ | $^3\log 3 = 1$ |
| $^a\log(bc) = ^a\log b + ^a\log c$ | $^2\log 24 = ^2\log 8 + ^2\log 3 = 3 + ^2\log 3$ |
| $^a\log\left(\frac{b}{c}\right) = ^a\log b - ^a\log c$ | $^3\log 18 - ^3\log 2 = ^3\log 9 = 2$ |
| $^a\log b^n = n \cdot ^a\log b$ | $^2\log 32 = ^2\log 2^5 = 5$ |
| $^{a^m}\log b^n = \frac{n}{m} \cdot ^a\log b$ | $^{8}\log 16 = ^{2^3}\log 2^4 = \frac{4}{3}$ |
| $^a\log b = \frac{^c\log b}{^c\log a} = \frac{1}{^b\log a}$ | $^4\log 5 = \frac{\log 5}{\log 4}; \ ^2\log 3 = \frac{1}{^3\log 2}$ |
| $^a\log b \cdot ^b\log c = ^a\log c$ | $^2\log 3 \cdot ^3\log 8 = ^2\log 8 = 3$ |
| $a^{^a\log b} = b$ | $5^{^5\log 7} = 7$ |
| $a^{^c\log b} = b^{^c\log a}$ | $2^{^3\log 5} = 5^{^3\log 2}$ |
| Asimtot Tegak $f(x) = ^a\log x$: Garis $x = 0$ | $f(x) = \log(x - 3) \implies \text{Asimtot tegak: } x = 3$ |
| Pertidaksamaan ($a > 1$): $^a\log f(x) > ^a\log g(x)$ | $^2\log(x-1) > 2 \implies x-1 > 4 \implies x > 5$ |
| Pertidaksamaan ($0 < a < 1$): tanda berbalik | $^{0.5}\log x > 1 \implies 0 < x < 0.5^1 \implies 0 < x < 0.5$ |
