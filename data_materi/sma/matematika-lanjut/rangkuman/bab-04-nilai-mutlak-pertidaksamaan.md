## 4. Nilai Mutlak & Pertidaksamaan
| Sifat / Rumus                                                             | Contoh Aplikasi                                                                                    |
| :------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------- |
| Definisi: $\vert x \vert = x \ (x \ge 0); \ \vert x \vert = -x \ (x < 0)$ | $\vert 5 \vert = 5; \ \vert -5 \vert = -(-5) = 5$                                                  |
| $\vert f(x) \vert \le a \iff -a \le f(x) \le a$                           | $\vert x - 3 \vert \le 2 \implies -2 \le x - 3 \le 2 \implies 1 \le x \le 5$                       |
| $\vert f(x) \vert \ge a \iff f(x) \le -a \lor f(x) \ge a$                 | $\vert 2x - 1 \vert \ge 5 \implies 2x - 1 \le -5 \lor 2x - 1 \ge 5 \implies x \le -2 \lor x \ge 3$ |
| $\vert f(x) \vert \le \vert g(x) \vert \iff (f+g)(f-g) \le 0$             | $\vert x+1 \vert \le \vert 2x-4 \vert \implies (3x-3)(-x+5) \le 0 \implies x \le 1 \lor x \ge 5$   |
| Rasional: $\frac{P(x)}{Q(x)} \le 0 \implies Q(x) \neq 0$                  | $\frac{x-1}{x+3} \le 0 \implies -3 < x \le 1$                                                      |
| Irasional: $\sqrt{f(x)} < g(x) \implies f \ge 0, g > 0, f < g^2$          | $\sqrt{x-2} < 3 \implies x \ge 2 \land x - 2 < 9 \implies 2 \le x < 11$                            |
