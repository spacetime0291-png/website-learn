## 11. Trigonometri Dasar & Analitis
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| $\sin^2\alpha + \cos^2\alpha = 1$ | $\sin\alpha = \frac{3}{5} \implies \cos\alpha = \sqrt{1 - \frac{9}{25}} = \frac{4}{5}$ |
| $1 + \tan^2\alpha = \sec^2\alpha$ | $\tan\alpha = 1 \implies \sec^2\alpha = 2 \implies \sec\alpha = \sqrt{2}$ |
| $1 + \cot^2\alpha = \csc^2\alpha$ | Hubungan identitas kotangen dan kosekan |
| Kuadran II: $\sin(180^\circ - \alpha) = \sin\alpha$ | $\sin 150^\circ = \sin(180^\circ - 30^\circ) = \sin 30^\circ = \frac{1}{2}$ |
| Kuadran III: $\tan(180^\circ + \alpha) = \tan\alpha$ | $\tan 240^\circ = \tan(180^\circ + 60^\circ) = \tan 60^\circ = \sqrt{3}$ |
| Kuadran IV: $\cos(360^\circ - \alpha) = \cos\alpha$ | $\cos 315^\circ = \cos(360^\circ - 45^\circ) = \cos 45^\circ = \frac{1}{2}\sqrt{2}$ |
| Sudut Negatif: $\sin(-\alpha) = -\sin\alpha$ | $\sin(-30^\circ) = -\sin 30^\circ = -\frac{1}{2}$ |
| Sudut Negatif: $\cos(-\alpha) = \cos\alpha$ | $\cos(-60^\circ) = \cos 60^\circ = \frac{1}{2}$ |
| Sudut Negatif: $\tan(-\alpha) = -\tan\alpha$ | $\tan(-45^\circ) = -\tan 45^\circ = -1$ |
| Persamaan: $\sin x = \sin\alpha \implies x = \alpha + k \cdot 360^\circ \lor (180^\circ-\alpha) + k \cdot 360^\circ$ | $\sin x = \frac{1}{2} \implies x = 30^\circ \lor x = 150^\circ$ |
| Persamaan: $\cos x = \cos\alpha \implies x = \pm\alpha + k \cdot 360^\circ$ | $\cos x = \frac{1}{2}\sqrt{2} \implies x = \pm 45^\circ + k \cdot 360^\circ$ |
| Persamaan: $\tan x = \tan\alpha \implies x = \alpha + k \cdot 180^\circ$ | $\tan x = \sqrt{3} \implies x = 60^\circ + k \cdot 180^\circ$ |
| Aturan Sinus: $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ | $a = 8, \angle A = 30^\circ \implies 2R = \frac{8}{0.5} = 16 \implies R = 8$ |
| Aturan Cosinus: $a^2 = b^2 + c^2 - 2bc\cos A$ | $b=3, c=5, \angle A=60^\circ \implies a^2 = 9 + 25 - 2(3)(5)(0.5) = 19$ |
| Luas Segitiga: $L = \frac{1}{2}ab\sin C$ | $a = 4, b = 6, \angle C = 30^\circ \implies L = \frac{1}{2}(4)(6)(0.5) = 6$ |
| Luas Segitiga Heron: $L = \sqrt{s(s-a)(s-b)(s-c)}$ | Menghitung luas dari ketiga panjang sisi ($s = \frac{a+b+c}{2}$) |
| $\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$ | $\sin 75^\circ = \sin(45^\circ+30^\circ) = \frac{\sqrt{6}+\sqrt{2}}{4}$ |
| $\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$ | $\cos 75^\circ = \cos(45^\circ+30^\circ) = \frac{\sqrt{6}-\sqrt{2}}{4}$ |
| $\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$ | Rumus penjumlahan tangen sudut |
| $\sin 2\alpha = 2\sin\alpha\cos\alpha$ | $\sin\alpha=0.6, \cos\alpha=0.8 \implies \sin 2\alpha = 2(0.6)(0.8) = 0.96$ |
| $\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$ | Sudut ganda cosinus |
| $\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha}$ | Sudut ganda tangen |
| $\sin^2\alpha = \frac{1 - \cos 2\alpha}{2}$ | Mereduksi derajat kuadrat ke sudut linear |
| $\cos^2\alpha = \frac{1 + \cos 2\alpha}{2}$ | Mereduksi derajat kuadrat cosinus |
| $2\sin\alpha\cos\beta = \sin(\alpha+\beta) + \sin(\alpha-\beta)$ | Perkalian sinus-cosinus ke bentuk penjumlahan |
| $2\cos\alpha\cos\beta = \cos(\alpha+\beta) + \cos(\alpha-\beta)$ | Perkalian dua cosinus ke penjumlahan cosinus |
| $-2\sin\alpha\sin\beta = \cos(\alpha+\beta) - \cos(\alpha-\beta)$ | Perkalian dua sinus ke selisih cosinus |
| $\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$ | Penjumlahan sinus ke perkalian |
| $\cos A - \cos B = -2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$ | Selisih cosinus ke perkalian dua sinus |
| $a\cos x + b\sin x = k\cos(x - \alpha)$ | $k = \sqrt{a^2 + b^2}, \ \tan\alpha = \frac{b}{a}$ |
