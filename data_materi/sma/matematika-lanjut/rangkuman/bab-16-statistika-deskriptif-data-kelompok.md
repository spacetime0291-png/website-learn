## 16. Statistika Deskriptif Data Kelompok
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| Mean Data Kelompok: $\bar{x} = \frac{\sum f_i x_i}{\sum f_i}$ | Rata-rata dari perkalian frekuensi dengan titik tengah kelas |
| Rata-rata Gabungan: $\bar{x}_{\text{gab}} = \frac{n_1\bar{x}_1 + n_2\bar{x}_2}{n_1 + n_2}$ | 10 siswa nilai 80 dan 20 siswa nilai 95 $\implies \bar{x} = \frac{800 + 1900}{30} = 90$ |
| Median: $Me = T_b + \left(\frac{\frac{1}{2}N - \sum f_k}{f_{me}}\right) \cdot c$ | Nilai tengah data kelompok berfrekuensi total $N$ |
| Modus: $Mo = T_b + \left(\frac{d_1}{d_1 + d_2}\right) \cdot c$ | Nilai dengan frekuensi terbesar ($d_1 = f_{mo} - f_{mo-1}, d_2 = f_{mo} - f_{mo+1}$) |
| Kuartil ke-$i$: $Q_i = T_b + \left(\frac{\frac{i}{4}N - \sum f_k}{f_{Q_i}}\right) \cdot c$ | Nilai pemecah data menjadi 4 bagian sama besar ($i = 1, 2, 3$) |
| Jangkauan (Range): $R = x_{\max} - x_{\min}$ | Selisih datum tertinggi dan datum terendah |
| Hamparan: $H = Q_3 - Q_1$ | Selisih antarkuartil |
| Simpangan Kuartil: $Q_d = \frac{1}{2}H = \frac{1}{2}(Q_3 - Q_1)$ | Setengah dari jangkauan antarkuartil |
| Simpangan Rata-rata: $SR = \frac{\sum f_i \vert x_i - \bar{x}\vert}{\sum f_i}$ | Rerata jarak absolut setiap data terhadap nilai rata-ratanya |
| Ragam (Varians): $S^2 = \frac{\sum f_i (x_i - \bar{x})^2}{\sum f_i}$ | Rata-rata kuadrat deviasi data |
| Simpangan Baku: $S = \sqrt{S^2}$ | Akar kuadrat dari nilai varians |
| Angka Baku ($Z$-Score): $Z = \frac{x - \bar{x}}{S}$ | Nilai $x = 88, \bar{x} = 80, S = 4 \implies Z = \frac{88 - 80}{4} = 2$ |
| Koefisien Variasi: $KV = \frac{S}{\bar{x}} \times 100\%$ | Mengukur dispersi relatif data |
| Transformasi $+b$: Pemusatan & Letak berubah $+b$ | Rata-rata awal 60 ditambah 5 $\implies$ Rata-rata baru $= 65$ |
| Transformasi $+b$: Ukuran Penyebaran **TETAP** | Simpangan baku awal 8 ditambah 5 $\implies$ Simpangan baku baru $= 8$ |
| Transformasi $\times a$: Seluruh Ukuran berubah $\times \vert a \vert$ | Simpangan baku awal 8 dikali 2 $\implies$ Simpangan baku baru $= 16$ |
| Transformasi $\times a$: Varians berubah $\times a^2$ | Varians awal 10 dikali 3 $\implies$ Varians baru $= 3^2 \times 10 = 90$ |
