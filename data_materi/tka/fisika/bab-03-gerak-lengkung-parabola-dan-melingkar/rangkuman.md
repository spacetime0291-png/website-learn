# Rangkuman Rumus Cepat — Gerak Lengkung (Parabola dan Melingkar)
**Kategori:** TKA Fisika | **Pembungkus:** Kinematika

### A. Tabel Analisis Komponen Gerak Parabola
| Parameter Gerak | Sumbu X (Horisontal - GLB) | Sumbu Y (Vertikal - GLBB) |
| :--- | :--- | :--- |
| **Kecepatan Awal** | $v_{0x} = v_0 \cos\theta$ | $v_{0y} = v_0 \sin\theta$ |
| **Kecepatan Sesaat ($t$)** | $v_x = v_0 \cos\theta$ (konstan) | $v_y = v_0 \sin\theta - gt$ |
| **Posisi Sesaat ($t$)** | $x = (v_0 \cos\theta) \cdot t$ | $y = (v_0 \sin\theta)t - \frac{1}{2}gt^2$ |
| **Puncak Tertinggi** | $t_{\text{puncak}} = \frac{v_0 \sin\theta}{g}$ | $h_{\max} = \frac{v_0^2 \sin^2\theta}{2g}$ |
| **Jarak Terjauh** | $t_{\text{total}} = \frac{2v_0 \sin\theta}{g}$ | $X_{\max} = \frac{v_0^2 \sin 2\theta}{g}$ |

### B. Tabel Komparasi Gerak Melingkar (GMB vs GMBB)
| Besaran Sudut | Hubungan Linier | GMB ($\alpha = 0$) | GMBB ($\alpha = \text{konstan}$) |
| :--- | :--- | :--- | :--- |
| **Posisi Sudut ($\theta$)** | $s = \theta R$ | $\theta = \omega t$ | $\theta = \omega_0 t + \frac{1}{2}\alpha t^2$ |
| **Kecepatan Sudut ($\omega$)** | $v = \omega R$ | $\omega = \frac{2\pi}{T} = 2\pi f$ | $\omega_t = \omega_0 + \alpha t$ |
| **Percepatan Sentripetal ($a_s$)** | $a_s = \frac{v^2}{R} = \omega^2 R$ | Arah radial ke pusat | Percepatan total: $a = \sqrt{a_s^2 + a_t^2}$ |

> [!TIP] Nilai Maksimum Parabola:
> Jarak tembak $X_{\max}$ bernilai paling besar saat sudut elevasi $\theta = 45^\circ$ (karena $\sin 90^\circ = 1$).
