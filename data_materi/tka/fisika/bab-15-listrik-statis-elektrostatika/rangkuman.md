# Rangkuman Rumus Cepat — Listrik Statis (Elektrostatika)
**Kategori:** TKA Fisika | **Pembungkus:** Kelistrikan

### A. Tabel Matriks 4 Besaran Pokok Elektrostatika
| Besaran | Sifat / Jenis | Formulasi Matematis | Satuan SI |
| :--- | :--- | :--- | :--- |
| **Gaya Coulomb ($F$)** | Vektor | $F = k \frac{|q_1 q_2|}{r^2}$ | Newton ($\text{N}$) |
| **Kuat Medan Listrik ($E$)** | Vektor | $E = k \frac{|q|}{r^2}, \quad F = qE$ | $\text{N/C}$ atau $\text{V/m}$ |
| **Energi Potensial Listrik ($E_p$)** | Skalar (tanda muatan diikutkan) | $E_p = k \frac{q_1 q_2}{r}$ | Joule ($\text{J}$) |
| **Potensial Listrik ($V$)** | Skalar (tanda muatan diikutkan) | $V = k \frac{q}{r}, \quad E_p = qV$ | Volt ($\text{V}$) |
| **Usaha Perpindahan Muatan** | Skalar | $W_{1\to2} = q(V_2 - V_1) = \Delta E_p$ | Joule ($\text{J}$) |

### B. Tabel Bola Konduktor Berongga ($R = \text{jari-jari bola}$)
| Wilayah Posisi Titik ($r$) | Kuat Medan Listrik ($E$) | Potensial Listrik ($V$) |
| :--- | :--- | :--- |
| **Di Dalam Bola ($r < R$)** | $E = 0$ (muatan hanya tersebar di kulit) | $V = k \frac{q}{R}$ (sama rata dengan kulit) |
| **Di Kulit Bola ($r = R$)** | $E = k \frac{q}{R^2}$ | $V = k \frac{q}{R}$ |
| **Di Luar Bola ($r > R$)** | $E = k \frac{q}{r^2}$ | $V = k \frac{q}{r}$ |

### C. Tabel Kapasitor Keping Sejajar
| Parameter Kapasitor | Tanpa Dielektrik (Udara) | Dengan Bahan Dielektrik ($\varepsilon_r$) |
| :--- | :--- | :--- |
| **Kapasitansi ($C$)** | $C_0 = \varepsilon_0 \frac{A}{d}$ | $C = \varepsilon_r C_0 = \varepsilon_r \varepsilon_0 \frac{A}{d}$ |
| **Energi Tersimpan ($W$)** | $W = \frac{1}{2}QV = \frac{1}{2}CV^2 = \frac{Q^2}{2C}$ | Satuan SI: Joule ($\text{J}$) |
| **Rangkaian Seri** | $\frac{1}{C_s} = \frac{1}{C_1} + \frac{1}{C_2}$, muatan sama ($Q_1 = Q_2$) | Tegangan terbagi: $V = V_1 + V_2$ |
| **Rangkaian Paralel** | $C_p = C_1 + C_2$, tegangan sama ($V_1 = V_2$) | Muatan terbagi: $Q = Q_1 + Q_2$ |
