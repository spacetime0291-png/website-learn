## 1. Eksponen & Bentuk Akar
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| $a^m \cdot a^n = a^{m+n}$ | $2^3 \cdot 2^4 = 2^7 = 128$ |
| $\frac{a^m}{a^n} = a^{m-n}$ | $\frac{3^5}{3^2} = 3^3 = 27$ |
| $(a^m)^n = a^{m \cdot n}$ | $(2^3)^2 = 2^6 = 64$ |
| $(a \cdot b)^n = a^n \cdot b^n$ | $(2 \cdot 5)^3 = 2^3 \cdot 5^3 = 1000$ |
| $\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}, \ b \neq 0$ | $\left(\frac{3}{2}\right)^3 = \frac{27}{8}$ |
| $a^0 = 1, \ a \neq 0$ | $7^0 = 1$ |
| $a^{-n} = \frac{1}{a^n}, \ a \neq 0$ | $5^{-2} = \frac{1}{25}$ |
| $a^{\frac{m}{n}} = \sqrt[n]{a^m}$ | $8^{\frac{2}{3}} = \sqrt[3]{8^2} = 4$ |
| $p\sqrt{a} \pm q\sqrt{a} = (p \pm q)\sqrt{a}$ | $5\sqrt{3} + 2\sqrt{3} = 7\sqrt{3}$ |
| $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$ | $\sqrt{2} \cdot \sqrt{8} = \sqrt{16} = 4$ |
| $\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$ | $\frac{\sqrt{50}}{\sqrt{2}} = \sqrt{25} = 5$ |
| $\frac{c}{\sqrt{a}} = \frac{c}{a}\sqrt{a}$ | $\frac{6}{\sqrt{3}} = \frac{6}{3}\sqrt{3} = 2\sqrt{3}$ |
| $\frac{c}{\sqrt{a} \pm \sqrt{b}} = \frac{c(\sqrt{a} \mp \sqrt{b})}{a - b}$ | $\frac{2}{\sqrt{5}-\sqrt{3}} = \frac{2(\sqrt{5}+\sqrt{3})}{5-3} = \sqrt{5}+\sqrt{3}$ |
| $\sqrt{(a+b) \pm 2\sqrt{ab}} = \sqrt{a} \pm \sqrt{b} \ (a > b)$ | $\sqrt{8 + 2\sqrt{15}} = \sqrt{5} + \sqrt{3}$ |
| Asimtot Datar $f(x) = a^x$: Garis $y = 0$ | $\lim_{x \to -\infty} 2^x = 0 \implies \text{Asimtot datar: } y = 0$ |
