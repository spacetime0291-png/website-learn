## 3. Persamaan & Fungsi Kuadrat
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| Akar Kuadratik: $x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$ | $x^2 - 4x + 3 = 0 \implies x_{1,2} = \frac{4 \pm \sqrt{4}}{2} \implies x = 3 \lor x = 1$ |
| Diskriminan: $D = b^2 - 4ac$ | $x^2 - 2x + 5 = 0 \implies D = (-2)^2 - 4(1)(5) = -16$ |
| $D > 0 \implies 2$ akar real berbeda | $x^2 - 5x + 6 = 0 \ (D = 1) \implies x_1 = 2, x_2 = 3$ |
| $D = 0 \implies 2$ akar real kembar | $x^2 - 6x + 9 = 0 \ (D = 0) \implies x_1 = x_2 = 3$ |
| $D < 0 \implies$ Tidak ada akar real | $x^2 + x + 2 = 0 \ (D = -7 < 0)$ |
| $x_1 + x_2 = -\frac{b}{a}$ | $2x^2 - 8x + 6 = 0 \implies x_1 + x_2 = -\frac{-8}{2} = 4$ |
| $x_1 \cdot x_2 = \frac{c}{a}$ | $2x^2 - 8x + 6 = 0 \implies x_1 x_2 = \frac{6}{2} = 3$ |
| $\vert x_1 - x_2 \vert = \frac{\sqrt{D}}{\vert a \vert}$ | $x^2 - 5x + 6 = 0 \implies \vert x_1 - x_2 \vert = \frac{\sqrt{1}}{1} = 1$ |
| $x_1^2 + x_2^2 = (x_1+x_2)^2 - 2x_1x_2$ | $x_1+x_2=4, x_1x_2=3 \implies 4^2 - 2(3) = 10$ |
| Persamaan Baru: $x^2 - (\alpha+\beta)x + \alpha\beta = 0$ | Akar 2 dan $-4 \implies x^2 - (-2)x + (-8) = x^2 + 2x - 8 = 0$ |
| Puncak Parabola: $\left(-\frac{b}{2a}, -\frac{D}{4a}\right)$ | $y = x^2 - 4x + 1 \implies x_p = 2, y_p = -3 \implies (2, -3)$ |
| Definit Positif: $a > 0 \land D < 0$ | $f(x) = x^2 + 2x + 3 \ (a=1>0, D=-8<0) \implies f(x) > 0, \forall x$ |
| Definit Negatif: $a < 0 \land D < 0$ | $f(x) = -x^2 + 2x - 4 \ (a=-1<0, D=-12<0) \implies f(x) < 0, \forall x$ |
