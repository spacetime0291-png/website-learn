## 5. Sistem Persamaan & Program Linear
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| Aturan Cramer: $x = \frac{D_x}{D}, y = \frac{D_y}{D}$ | $D = 2, D_x = 6, D_y = -4 \implies x = 3, y = -2$ |
| Solusi Tunggal SPL: $D \neq 0$ | Matriks koefisien memiliki determinan bukan nol |
| Tak Hingga Solusi: $D = D_x = D_y = 0$ | Kedua garis berimpit |
| Tidak Ada Solusi: $D = 0 \land (D_x \neq 0 \lor D_y \neq 0)$ | Kedua garis sejajar tidak berpotongan |
| Uji Titik Pojok Fungsi Objektif $Z = ax + by$ | Titik $(2, 5)$ pada $Z = 3x + 4y \implies Z = 3(2) + 4(5) = 26$ |
