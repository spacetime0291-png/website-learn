## 8. Irisan Kerucut (Lingkaran, Parabola, Elips, Hiperbola)
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| Lingkaran Pusat $(a,b)$: $(x-a)^2 + (y-b)^2 = r^2$ | Pusat $(2, -1), r = 3 \implies (x-2)^2 + (y+1)^2 = 9$ |
| Jari-jari Umum: $r = \sqrt{\frac{A^2}{4} + \frac{B^2}{4} - C}$ | $x^2 + y^2 - 4x + 6y - 12 = 0 \implies r = \sqrt{4 + 9 - (-12)} = 5$ |
| PGS Lingkaran Gradien $m$: $y-b = m(x-a) \pm r\sqrt{1+m^2}$ | $x^2 + y^2 = 4, m = 1 \implies y = x \pm 2\sqrt{2}$ |
| Parabola $y^2 = 4px \implies$ Fokus $(p, 0)$, Direktriks $x = -p$ | $y^2 = 12x \implies 4p=12 \implies p=3 \implies$ Fokus $(3, 0)$, Direktriks $x=-3$ |
| PGS Parabola $y^2 = 4px$ Gradien $m$: $y = mx + \frac{p}{m}$ | $y^2 = 8x, m = 2 \implies y = 2x + \frac{2}{2} = 2x + 1$ |
| Elips Horizontal: $\frac{(x-h)^2}{a^2} + \frac{(y-k)^2}{b^2} = 1 \ (a > b)$ | $\frac{x^2}{25} + \frac{y^2}{9} = 1 \implies a=5, b=3, c=\sqrt{25-9}=4$ |
| Eksentrisitas Elips: $e = \frac{c}{a} < 1$ | $\frac{x^2}{25} + \frac{y^2}{9} = 1 \implies e = \frac{4}{5} = 0.8$ |
| Hiperbola Horizontal: $\frac{(x-h)^2}{a^2} - \frac{(y-k)^2}{b^2} = 1$ | $\frac{x^2}{16} - \frac{y^2}{9} = 1 \implies a=4, b=3, c=\sqrt{16+9}=5$ |
| **Asimtot Hiperbola Horizontal:** $y - k = \pm\frac{b}{a}(x - h)$ | $\frac{x^2}{16} - \frac{y^2}{9} = 1 \implies \text{Asimtot: } y = \pm\frac{3}{4}x$ |
| **Asimtot Hiperbola Vertikal:** $y - k = \pm\frac{a}{b}(x - h)$ | $\frac{y^2}{16} - \frac{x^2}{9} = 1 \implies \text{Asimtot: } y = \pm\frac{4}{3}x$ |
