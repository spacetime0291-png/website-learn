## 9. Geometri Ruang (Dimensi Tiga)
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| Diagonal Bidang Kubus: $d_b = s\sqrt{2}$ | Rusuk $s = 6\text{ cm} \implies d_b = 6\sqrt{2}\text{ cm}$ |
| Diagonal Ruang Kubus: $d_r = s\sqrt{3}$ | Rusuk $s = 6\text{ cm} \implies d_r = 6\sqrt{3}\text{ cm}$ |
| Jarak Sudut ke Diagonal Ruang: $d = \frac{s}{3}\sqrt{6}$ | Rusuk $s = 6\text{ cm} \implies d = \frac{6}{3}\sqrt{6} = 2\sqrt{6}\text{ cm}$ |
| Jarak Sudut ke Bidang Seberang: $d = \frac{s}{3}\sqrt{3}$ | Rusuk $s = 6\text{ cm} \implies d = 2\sqrt{3}\text{ cm}$ |
| Jarak Titik ke Garis: Luas Segitiga $\frac{1}{2}a_1 t_1 = \frac{1}{2}a_2 t_2$ | Mencari tinggi proyeksi tegak lurus pada segitiga siku-siku |
| Jarak Garis Bersilangan $g$ dan $h$ | Jarak titik pada garis $g$ ke bidang yang memuat garis $h$ dan sejajar $g$ |
