## 13. Turunan (Diferensial) & Aplikasi
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| Aturan Pangkat: $\frac{d}{dx}(ax^n) = a \cdot n x^{n-1}$ | $\frac{d}{dx}(4x^3) = 12x^2$ |
| Aturan Perkalian: $(uv)' = u'v + uv'$ | $(x^2 \cdot \sin x)' = 2x\sin x + x^2\cos x$ |
| Aturan Pembagian: $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ | Turunan bentuk pecahan aljabar |
| Aturan Rantai: $[f(g(x))]' = f'(g(x)) \cdot g'(x)$ | $\frac{d}{dx}(3x-2)^4 = 4(3x-2)^3 \cdot 3 = 12(3x-2)^3$ |
| Turunan Implisit: $\frac{d}{dx}(y^2) = 2y \frac{dy}{dx}$ | $x^2 + y^2 = 16 \implies 2x + 2y y' = 0 \implies y' = -\frac{x}{y}$ |
| $[\sin x]' = \cos x$ | Turunan dasar sinus |
| $[\cos x]' = -\sin x$ | Turunan dasar cosinus |
| $[\tan x]' = \sec^2 x$ | Turunan dasar tangen |
| $[\cot x]' = -\csc^2 x$ | Turunan dasar kotangen |
| $[\sec x]' = \sec x \tan x$ | Turunan dasar sekan |
| $[\csc x]' = -\csc x \cot x$ | Turunan dasar kosekan |
| Gradien Garis Singgung: $m_s = f'(x_1)$ | $f(x) = x^2$ di $x=3 \implies m_s = 2(3) = 6$ |
| Persamaan Garis Singgung: $y - y_1 = m_s(x - x_1)$ | Titik $(3, 9), m=6 \implies y - 9 = 6(x - 3)$ |
| Gradien Garis Normal: $m_n = -\frac{1}{m_s}$ | $m_s = 2 \implies m_n = -\frac{1}{2}$ |
| Fungsi Naik: $f'(x) > 0$; Fungsi Turun: $f'(x) < 0$ | Menentukan interval kemonotonan kurva |
| Titik Stasioner: $f'(x) = 0$ | Mencari kandidat titik puncak maksimum/minimum |
| Uji Turunan Kedua: $f''(c) < 0 \implies$ Titik Balik Maksimum | Kurva cekung ke bawah di sekitar titik puncak |
| Uji Turunan Kedua: $f''(c) > 0 \implies$ Titik Balik Minimum | Kurva cekung ke atas di sekitar titik lembah |
| Titik Belok: $f''(c) = 0$ dan terjadi pergantian kecekungan | Titik peralihan antara cekung ke atas dan cekung ke bawah |
| Kecepatan & Percepatan: $v(t) = s'(t), \ a(t) = v'(t) = s''(t)$ | $s(t) = t^3 \implies v(t) = 3t^2 \implies a(t) = 6t$ |
