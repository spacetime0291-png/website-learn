## 17. Statistika Inferensial & Distribusi Peluang
| Sifat / Rumus | Contoh Aplikasi |
| :--- | :--- |
| Syarat Peluang Diskrit: $\sum P(X = x) = 1$ | Total peluang seluruh variabel acak diskrit harus bernilai 1 |
| Nilai Harapan Diskrit: $\mu = E(X) = \sum x \cdot P(X = x)$ | Rata-rata teoretis kemunculan nilai acak |
| Varians Diskrit: $\sigma^2 = \sum x^2 P(X = x) - \mu^2$ | Tolok ukur penyebaran variabel acak diskrit |
| Binomial: $P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$ | Muncul 2 Gambar dari 3 lemparan koin $\implies \binom{3}{2}(0.5)^2(0.5)^1 = 0.375$ |
| Nilai Harapan Binomial: $\mu = n \cdot p$ | 100 percobaan dengan $p = 0.3 \implies \mu = 100(0.3) = 30$ |
| Varians Binomial: $\sigma^2 = n \cdot p \cdot (1 - p)$ | 100 percobaan, $p = 0.3 \implies \sigma^2 = 100(0.3)(0.7) = 21$ |
| Simpangan Baku Binomial: $\sigma = \sqrt{n \cdot p \cdot (1 - p)}$ | $\sigma = \sqrt{21} \approx 4.58$ |
| Distribusi Normal Baku ($Z$): $Z = \frac{X - \mu}{\sigma}$ | Menstandardisasi data kontinu ke distribusi normal standar $N(0, 1)$ |
| Sifat Kurva Normal Baku | Luas total di bawah kurva lonceng $= 1$; Luas $P(Z \le 0) = 0.5$ |
